BluePanel

Bluetooth Low Energy dashboard for ESP32 devices. The phone connects directly to the device, shows its values live, sends commands, and records sessions. No Internet, account or server is involved.

What the project demonstrates

Bluetooth Low Energy client

Scanning, connection, GATT service discovery, read, write and notifications, with MTU negotiation and handling of lost connections.

Message protocol over BLE

JSON lines over the Nordic UART Service, reassembled from fragmented notifications. Every write is confirmed by the device before the screen shows it.

Configurable real-time dashboard

Value tiles, switches, momentary buttons, sliders with rate-limited writes, and live line charts, saved as profiles per kind of device.

Local data logging

Sessions stored in an on-device SQLite database, with minimum, maximum and average per variable and CSV export through the Android share sheet.

Embedded firmware

ESP32 firmware in C++ (PlatformIO, Arduino framework, NimBLE) that exposes sensor values and outputs through the same protocol.

Hybrid Android architecture

React and Ionic interface in a Capacitor shell, with all Bluetooth access behind one interface so the whole UI also runs against a simulated device.

How to install and test

  1. Download the APK on an Android phone (Android 6.0 or later).
  2. Open the downloaded file from the browser or the file manager.
  3. Android asks for permission to install apps from that source the first time. Allow it for the browser or file manager you used, then follow the installation prompts.
  4. Open BluePanel and allow access to nearby devices (on Android 11 or earlier, location access, which those versions require for any Bluetooth scan).
  5. Turn Bluetooth on and scan.

The app works entirely offline. It needs a phone with Bluetooth Low Energy.

The dashboard, terminal and session recording need a device that implements the BluePanel protocol, such as an ESP32 running the demonstration firmware. That firmware is not distributed on this page. Without such a device, the scanner and the BLE explorer can still be tried with other Bluetooth Low Energy devices nearby.

Suggested demonstration

With an ESP32 running the demonstration firmware

Connect to the device and open the Dashboard tab. Create a profile, add widgets for the variables the device reports, switch the LED, move the PWM slider and watch the chart. Then open the Logs tab, record a session for a minute, review the statistics and export it as CSV.

Without an ESP32

Scan, filter the list by name, and connect to a nearby BLE device that accepts connections. In the Services tab, browse its GATT services and characteristics and read a value, shown as hexadecimal, text and integer.

Technical architecture

  1. InterfaceReact, Ionic, TypeScript
  2. App state and protocolZustand store, line framing, JSON messages
  3. BleTransportCapacitor Bluetooth LE plugin over Android BluetoothGatt
  4. BLE linkNordic UART Service, notifications and writes
  5. ESP32NimBLE GATT server, sensors and outputs

Profiles are stored with Capacitor Preferences and recorded sessions in SQLite, both on the phone. CSV and profile files leave the phone only when the user shares them. The Bluetooth layer has a simulated implementation used for development and automated tests, which is how the screenshots above were taken.
